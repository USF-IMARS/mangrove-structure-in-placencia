Sampling Points

Each bubble marks a field station where trees were measured. Bubble size scales with the total biomass measured at that station; color matches the station’s lagoon sector (see the Sector Explorer for sector-level detail). Hover a bubble for its station id and totals.

Code 
map = {
  const m = L.map(mapDiv, { scrollWheelZoom: false }).setView([16.62, -88.34], 12);
  L.tileLayer("https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png", {
    attribution: '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a>',
    maxZoom: 19,
  }).addTo(m);
  return m;
}
Code 
maxBiomassPerPoint = Math.max(...biomassPoints.map((d) => d.total_biomass_kg))
biomassRadius = (v) => 4 + 14 * Math.sqrt(v / maxBiomassPerPoint)
Code 
pointsLayer = {
  const layer = L.layerGroup(
    biomassPoints.map((d) =>
      L.circleMarker([d.lat, d.long], {
        radius: biomassRadius(d.total_biomass_kg),
        color: "#333",
        weight: 1,
        fillColor: sectorColors[d.sector] ?? "#888",
        fillOpacity: 0.7,
      }).bindTooltip(
        `${sectorLabels[d.sector] ?? d.sector} station ${d.station_id}<br>
         ${d.n_trees} trees sampled &middot; ${d.total_biomass_kg.toFixed(1)} kg total biomass`
      )
    )
  );
  layer.addTo(map);
  return layer;
}

Bubble size scales with total measured biomass at that station.
